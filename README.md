## 날짜별 출조 도우미

작업 폴더에서 출조도우미-실행.bat을 두 번 눌러 실행하거나 아래 명령을 사용합니다.

    python fishing_integrated.py

별도 데스크톱 창에서 지역별 낚시 포인트의 오늘 시간대별 환경 점수를 확인할 수 있습니다. 바람·파고·수온·조류 모델을 자동 조회하고, 조과는 이 PC에 기록해 지역별 과거 어종을 살펴볼 수 있습니다. 국립해양조사원 공식 만조·간조 조회에는 공공데이터포털 인증키와 해당 지역 관측소 코드가 필요합니다.

조과 기록과 인증키는 기본적으로 내 컴퓨터에 저장되며 GitHub에 자동 업로드하지 않습니다. 홈페이지에 올릴 기록은 공개 체크 후 `data/outings.json`을 GitHub에 반영해야 홈페이지에 표시됩니다. 국립해양조사원 공식 조석예보에는 공공데이터포털 인증키와 지역별 관측소 코드가 필요합니다. 인증키는 `outing_config.json`에 로컬 저장되며 Git에 포함되지 않습니다.
